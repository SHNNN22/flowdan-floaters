# Flowdan Floaters v2

A p5.js simulation inspired by vitreous eye floaters.

## v2 changes

- brighter summer-blue sky;
- subtle animated cloud and light gradients;
- shorter post-swipe bounce;
- stronger damping;
- different mass, drag, spring and response per floater;
- some floaters barely react while others move more;
- single transparent PNG generates all visual variants.
